# GitHub Wiki mirror

The repository publishes a human-facing mirror of the Agent Knowledge Pack to the project Wiki:

<https://github.com/tkhjp/copilot-agent-knowledge-demo/wiki>

## Source of truth

Agents must use the versioned files in this repository as authoritative context:

- `docs/agent-knowledge/generated/`
- `docs/agent-knowledge/curated/`
- `artifacts/codegraph/`

The Wiki is intended for team browsing, onboarding, and provenance. It is regenerated by `.github/workflows/mirror-wiki.yml`; generated Wiki pages should not be edited directly.

## Published pages

- Home and sidebar navigation
- Generated system overview
- Generated Payment Service module knowledge
- Generated Payment Service test-impact index
- Curated domain rules
- Curated testing policy
